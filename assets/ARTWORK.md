## Vector graphics

The project cards, greeting, toolbox, and footer are original SVG assets generated by `scripts/build_artwork.py`. They include light and dark variants. The greeting respects `prefers-reduced-motion`; all content remains available as image alternative text.

Regenerate the SVG assets with:

```sh
python3 scripts/build_artwork.py
```

## Automatic updates

`.github/workflows/refresh-profile.yml` runs daily at approximately 02:23 UTC, and can also be run manually in GitHub Actions. It reads the public blog RSS feed and regenerates the contribution snake. It uses the repository's built-in `GITHUB_TOKEN`; no personal token or extra secret is needed. If the feed is unavailable, its previous entries are retained.

The contribution animation is generated by [Platane/snk](https://github.com/Platane/snk), used as an action at a pinned commit. The action's source is MIT-licensed. The snake data is read from the public contribution calendar. Colors match the profile's paper, sage, and burnt-orange palette. Its animation comes from the upstream generator; the local greeting separately implements reduced-motion support.

README blog content changes only between `<!-- BLOG:START -->` and `<!-- BLOG:END -->`. Other copy can be edited normally.
